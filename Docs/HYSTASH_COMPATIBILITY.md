# Optional HyStash compatibility

Compatible with HyStash (previously known as Wondrous Wardrobes).

HyThief 1.4.2 recognizes supported owned HyStash 1.4.0 wardrobes through native Hytale storage mechanics and persistent ownership metadata. HyStash owns wardrobe storage and generation; HyThief applies its existing successful-withdrawal, visual witness, native NPC response and pursuit-access rules. Both mods work independently, with no hard dependency or bridge plugin.

Not all wardrobes are owned or every NPC a witness. Player-placed and pre-existing unmarked wardrobes stay unowned. Browsing, deposits and rearrangement are not successful withdrawals. Install HyStash separately from its [existing CurseForge project](https://www.curseforge.com/hytale/mods/wonderous-wardrobes). Follow its upgrade instructions when replacing the former wardrobe package.

This compatibility documentation does not change HyThief's version, gameplay code or published 1.4.2 JAR. Requires Hytale 0.7.2.
